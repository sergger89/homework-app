# Homework App — Android-клиент

Лёгкий нативный клиент (WebView-обёртка) для веб-приложения. Не хранит и не дублирует логику
приложения — просто открывает ваш сервер в полноэкранном WebView с нужными для этого сайта
удобствами: сохранение сессии между запусками, загрузка файлов (аватарки, обложки книг, .epub,
.json-задания — включая множественный выбор и «Сделать фото»), корректная работа кнопки «Назад».

Адрес сервера не зашит в приложение — вводится и меняется прямо в приложении (экран настроек
при первом запуске, либо через ⚙️ в правом верхнем углу). Один и тот же APK подходит для любого
вашего развёртывания. Поддерживается только **https://** (без сертификата/по http приложение
работать не будет — таково было явное требование при разработке).

## Как собрать APK

Сборка происходит на публичных GitHub Actions раннерах, ничего локально ставить не нужно.

1. Закоммитьте папку `android-client/` (эту) в корень вашего репозитория вместе с
   `.github/workflows/android-build.yml` (тоже внутри этой папки — переместите его в
   `.github/workflows/android-build.yml` в корне репозитория, если у вас уже есть другие workflow).
2. Запушьте в `main`/`master`, либо запустите вручную: вкладка **Actions** →
   **Build Android APK** → **Run workflow**.
3. Через пару минут в результатах запуска (Artifacts) появится `homework-app-client-debug` —
   скачайте, внутри будет `app-debug.apk`.
4. Перенесите apk на телефон и установите (Android спросит разрешение "Установка из неизвестных
   источников" при первом сайдлоаде — это ожидаемо, приложение не из Google Play).

Сборка debug-типа — специально, чтобы не заводить keystore/секреты для личного использования.
Если понадобится подписанный release-билд (например, для публикации в Play Store) — потребуется
отдельно сгенерировать keystore и подключить `signingConfig`, сюда это осознанно не включено.

## Первый запуск

1. Открыть приложение — попадёте на экран настроек.
2. Ввести адрес сервера, обязательно с `https://` (например `https://homework.example.com`).
3. «Сохранить и подключиться» — приложение откроет ваш сервер, дальше всё работает как в браузере
   (тот же логин, те же роли — родитель/ребёнок/админ, без дополнительной настройки).

Сменить адрес позже можно через значок ⚙️ в правом верхнем углу.

## Замена иконки

Иконка уже подставлена (из присланного вами файла) во всех размерах:
`app/src/main/res/mipmap-*/ic_launcher*.png` — обычные значки для Android до 8, плюс
`ic_launcher_foreground.png` и `mipmap-anydpi-v26/ic_launcher.xml` — адаптивная иконка для
Android 8+. Если захотите заменить на другую картинку — проще всего попросить меня
перегенерировать все размеры под неё, чем делать вручную.

## Структура проекта

```
android-client/
  app/
    src/main/java/com/homeworkapp/client/
      MainActivity.kt      — WebView, загрузка файлов, кнопка "назад", обработка ошибок сети
      SettingsActivity.kt  — экран ввода/смены адреса сервера
      ServerConfig.kt      — хранение адреса в SharedPreferences
    src/main/res/          — разметка, строки, иконки
  build.gradle.kts, settings.gradle.kts, gradle.properties
.github/workflows/android-build.yml — CI-сборка APK на публичных раннерах
```

## Известные ограничения (осознанно не делали, т.к. не просили)

- Только https — без поддержки самоподписанных сертификатов и обычного http.
- Нет push-уведомлений о новых заданиях.
- Нет подписанной release-сборки/публикации в Play Store.
- Иконка не адаптируется под каждого пользователя динамически — это уже нативная иконка
  приложения, не связана с favicon, который можно менять в панели администратора веб-версии.
